# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub: open the **Security** tab of this
repository and choose **Report a vulnerability**
(https://github.com/sknallt23/n400-processing-times/security/advisories/new).

Include what you found, how to reproduce it, and what you think the impact is.
This is a personal project, so there is no formal response deadline, but
reports are read and acted on as quickly as practical.

## Scope

This repository contains a static web page and a scraper that reads public
USCIS processing-time data. It stores no user accounts, credentials or
personal data.
